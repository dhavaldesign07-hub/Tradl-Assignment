# FinFlix prototype (Tradl design exercise)

Clickable mobile prototype of FinFlix: helping a retail trader go from "what do I look at today?" to "I understand this idea", without returns, buy or sell language, or trades.

**Open it:** https://dhavaldesign07-hub.github.io/Tradl-Assignment/

**Main flow:** Home → Tap, Scan, Pay → One97 (Paytm) → Ask AI → Save → Done for today.
Only the main flow is clickable. The screens are exported from the Figma design.

All tabs and buttons are tappable. All data is sample data for this exercise.
